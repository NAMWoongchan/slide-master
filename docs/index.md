# PMOffice Slide Master

PMOffice Slide Master is a PMOffice distribution fork for creating editable
PowerPoint presentations for project management consulting, corporate training,
national R&D, EPC, and generative AI education.

## What it provides

- A workflow for producing native, editable PowerPoint (`.pptx`) files.
- A PMOffice Brand Preset for white-first, information-led presentation design.
- PMOffice documentation for installation, copyright scope, and distribution
  maintenance.

## 10-minute quick start

1. Clone and install the repository:

   ```powershell
   git clone https://github.com/NAMWoongchan/slide-master.git
   cd slide-master
   python -m pip install -r requirements.txt
   ```

2. Open the folder in ChatGPT Work locally or Codex Local.
3. Read [`PMOffice Quick Start`](PMOFFICE_QUICKSTART.md), then use the exact
   PMOffice Brand workspace path:

   ```text
   .claude/skills/ppt-master/templates/brands/pmoffice/를 사용해서 프로젝트 관리 교육용 PPT를 만들어 줘.
   ```
